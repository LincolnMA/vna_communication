Projeto MINI
================

MINI (MicroWave tanamnam tanamnam) é um projeto multidisciplinar que consiste no desenvolvimento de um protótipo de detector de fraturas ósseas por imageologia por microondas. O projeto integra vários componentes de software e hardware como: 

- Posicionador Linear
- VNA portátil
- API em python para o VNA
- Algoritmo de processamento de sinais
